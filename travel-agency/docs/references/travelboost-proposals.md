# TravelBoost — Proposals (reference)

**Source:** https://travelboost.app/products/proposals  
**Fetched:** 2026-10-01 (public marketing page)

## Positioning

CRM for travel agencies & tour operators; **Proposals** module included from Starter tier (unlimited proposals).

## Problems they claim to solve

- PDF/Word attachments → low conversion, no follow-up signal.
- ~90 min per proposal (copy-paste, pricing, photos, formatting).
- No visibility: opens, time on section, forwards, re-reads.

## Core capabilities (map to our quotation module)

| Capability | Notes for our build |
|------------|---------------------|
| Shareable interactive link | Full-screen web proposal; fallback PDF; no customer login |
| AI proposal draft | Destination + duration + budget → draft in ~2 min; human edit |
| Supplier rate cards | Itinerary lines tied to rates; live margin; rate-change flags |
| Engagement tracking | Open alerts, time-on-page per section, device/location |
| One-click acceptance | Accept → auto-invoice → online pay → booking confirmed |
| Layout | Mobile story / desktop magazine; galleries, embedded video |
| i18n | 15+ languages; currency per locale; margin still visible to agency |
| Branding | Logo, colors, fonts, T&Cs; Enterprise white-label + custom domain |
