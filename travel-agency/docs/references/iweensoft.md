# Iween — Travel technology (reference)

**Source:** https://www.iweensoft.com  
**Fetched:** 2026-10-01 (public marketing page)

## Positioning

Travel technology provider for **TAs, TMCs, OTAs** — modular, cloud-native, **API-first**.

## Pillars (map to our integration + ops layer)

| Pillar | Claims | Our takeaway |
|--------|--------|--------------|
| Blitzfast integrations | 30+ integrations; faster GTM; lower supplier integration cost | **API gateway + adapter pattern** for GDS/NDC/hotels/DMC/etc. |
| Profit machine | Dynamic fare/markup; ops productivity; maintenance savings | **Markup rules engine** + mid-office workflows |
| Robust tech | 99.9% SLA; 1M+ monthly transactions; modular architecture | Non-functional targets for our cloud stack |
| Support | 24/7; dedicated success managers | Ops model if we partner vs build |

## Customer story themes (qualitative)

- Mid-office visibility across agents and cities.
- 15–18+ supplier/API integrations in live deployments.
- Large agent networks (e.g. 6k–10k agents) on single platform.
- Revenue beyond air: DMT, AEPS, recharges (region-specific).

## Public scale claims (vendor — not verified by us)

- 10M+ bookings, 10+ countries, 300+ clients.

## Integration angle

Iween is the **inverse** of TravelBoost emphasis: heavy on **inventory/API mid-office**, lighter on public proposal UX in homepage messaging. Our architecture should **combine**: Iween-style integration hub + TravelBoost-style proposal/quote front.
