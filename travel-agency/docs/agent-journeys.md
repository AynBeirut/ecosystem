# Agent journey maps (Phase 0)

## Owner

1. Open **Today** → see team pipeline counts + wallet/credit alert.
2. **Money** → margin by agent, dues, export week.
3. Drill into deal → audit quote version + booking ref + deposit.

## Senior agent

1. **New inquiry** wizard: client → trip → quote draft (&lt;20 min goal).
2. Share link on WhatsApp → log activity.
3. On accept → record deposit → **Book** from same deal → PNR auto-attached.

## Sub-agent

1. **Today** → only assigned follow-ups.
2. **Book** with deal pre-selected; cannot see owner margin breakdown (optional policy).

## Customer (no login)

1. Opens proposal link on phone → scroll itinerary → **Accept**.
2. Pays deposit (method recorded by agency) → receives confirmation ref `QT-…` / receipt.
